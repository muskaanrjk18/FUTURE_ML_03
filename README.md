Resume / Candidate Screening System
Project Overview
This project is a Resume Screening System that automatically analyzes resumes and ranks candidates based on their skills and a given job description.
Objectives
- Extract skills from resume text.
- Match candidate skills with job requirements.
- Calculate skill matching scores.
- Rank candidates based on matching scores.
- Identify missing skills for each candidate.
Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Regular Expressions
- Jupyter Notebook
